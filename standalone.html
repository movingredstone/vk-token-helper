VK Standalone Token Helper

groups.edit, groups.getSettings 처럼 Standalone 앱에서만 허용되는 메서드용 토큰을 발급합니다. Mini App 토큰으로는 이 메서드들이 호출되지 않습니다.

0Standalone 앱 만들기 (최초 1회)
  1. VK Developers → 내 앱에서 새 앱 생성
  2. 타입은 반드시 Standalone-приложение 선택 (Mini App 아님)
  3. 만들어진 앱의 App ID 숫자를 아래에 입력

이미 Standalone 앱이 있으면 이 단계는 건너뛰세요.

1권한 승인 링크 만들기

offline을 켜면 토큰이 만료되지 않습니다. 자동화에는 편하지만, 유출되면 계속 유효하니 주의하세요.

2주소창 URL 붙여넣기
  1. 승인하면 빈 페이지로 이동합니다 (정상입니다)
  2. 브라우저 주소창 전체를 복사하세요 — 토큰이 # 뒤에 들어 있습니다
  3. 아래에 붙여넣으면 토큰만 뽑아드립니다
3발급된 토큰
Security
  • 토큰은 저장되지 않습니다 (localStorage / sessionStorage / cookie / 서버 전송 없음).
  • 페이지를 새로고침하거나 닫으면 토큰은 즉시 사라집니다.
  • Never commit your VK access token or client secret.
